# Citing

If you use SAGARI, please cite the paper that describes and validates the method:

> Waters, T. K., & Gültekin, K. 2026, *Schwarzschild Orbit-library Modeling with an Order of Magnitude Fewer
> Models: Adaptive Gaussian-process Sampling and a Case Study of M 86*, ApJ, submitted

and the software itself, archived on Zenodo:
[10.5281/zenodo.23386326](https://doi.org/10.5281/zenodo.23386326) (all versions). To identify the exact
code you ran, cite the DOI of that release instead; version 1.0.0 is
[10.5281/zenodo.23386327](https://doi.org/10.5281/zenodo.23386327).
